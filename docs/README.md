# Documentación de diseño

## `mockup-aprobado.html`

Propuesta de diseño aprobada por el cliente, tal cual se entregó. Es la
referencia contra la que se construyó el sitio: paleta, tipografías,
jerarquía, orden de secciones y textos salen de aquí.

Se conserva sin modificar. Si en el futuro hay discusión sobre por qué
algo está como está, este archivo es la fuente.

Las diferencias deliberadas respecto a este mockup, y el motivo de cada
una, están documentadas en el README principal, en la sección
«Qué se respetó del mockup y qué se añadió».

Los recuadros grises del mockup marcaban dónde irían las fotografías
reales de las unidades. Esas fotos ya están integradas; los originales
sin tratar viven en `src/photos/`.
